# Code of conduct

This is a small project. We want it to be a place where anyone can report a problem or ask a question without
being made to feel stupid.

## Expected
- Be kind and assume good intent.
- Stay on the topic of this tool.
- Keep other people's data private, including your own users' data: never post it here.

## Not accepted
- Insults, harassment, discrimination or personal attacks.
- Posting someone else's private information.
- Spam or advertising in issues and pull requests.

## What happens
The maintainers may edit or remove comments, close issues or pull requests, and block accounts that break these
rules. Report a problem to hello@kodev.dev; reports are kept private.
